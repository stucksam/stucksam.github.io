The shared idea

Normal attention looks across sequence position: at token t, which earlier tokens should matter? A normal residual connection looks across network depth in the simplest possible way: it always adds the immediately previous state to the new layer output.

Kimi Linear improves the first problem. Attention Residuals improves the second. The papers call this a sequence-depth duality: a model has two directions in which it can move information, across tokens and across layers.

The KDA lineage: write, correct, forget

KDA did not appear from nowhere. It is part of a sequence of increasingly capable fast-weight memories. In each version, a layer stores key/value associations in a small state matrix rather than keeping every prior key and value in a cache.

Vanilla linear attention only writes. It accumulates ktvtT at every step, so old and new associations eventually interfere. DeltaNet treats the state as an online predictor: before writing vt for key kt, it measures the current prediction and writes only the error. This is the classical delta rule from online learning.

Gated DeltaNet (GDN) then introduces a learned scalar αt per attention head. It shrinks the whole state before the correction, making memory duration data-dependent. This is a major improvement over permanent accumulation, but every channel in a head still shares one forgetting rate. KDA retains the delta update but replaces that scalar with a vector αt, so it can retain some features while rapidly clearing others.

Kimi Delta Attention (KDA)

Linear attention replaces the growing KV cache with a fixed-size matrix state S. On each token, it writes a key/value association to this state, then reads with the query. This makes generation cheap, but the same state must represent an ever longer past.

“Fixed-size” means the memory does not gain a new slot for every token. In ordinary attention, a 100,000-token prompt leaves 100,000 key/value pairs available to read later. In linear attention, all of that history is compressed into a matrix whose shape stays the same regardless of prompt length. This prevents a growing KV cache, but two memories can then compete for the same part of the state.

BASIC LINEAR ATTENTION

St = St−1 + ktvtT   ;   ot = StTqt

Reading the equation: ktvtT is an outer product: it writes one small key-to-value mapping into S. Multiplying StT by qt asks the state to return the value associated with a query that resembles that key. The superscript T means “transpose”: rows become columns so the matrix multiplication is defined.

The problem is interference: every new association is added forever. DeltaNet changes the update into a correction. If the current key already retrieves something from memory, it erases that prediction before writing the new value.

KDA adds a learned forget gate before the delta correction. The important detail is that αt is one gate per key channel, not one scalar per head. Individual memory dimensions can decay at different rates, giving it a richer position and recency signal.

There are two more learned controls. βt, constrained between zero and one, acts as the update rate: a small value barely revises the old association, while a large value strongly overwrites it. q, k, and v are not plain linear projections in Kimi Linear; the paper passes them through short convolutions and a Swish activation, then L2-normalizes q and k. The convolution provides local order cues, and normalization keeps the state transition numerically stable.

“Numerically stable” here means repeated updates do not make values explode toward enormous numbers or vanish toward zero. L2 normalization fixes the length of each q and k vector, limiting how large their dot products and rank-one updates can become. The short convolution looks at a small window of neighbouring tokens, giving KDA an additional clue about nearby order before its memory update.

KDA is not softmax attention made cheaper. It has a different memory model. Softmax attention can revisit any individual cached token; KDA compresses history into a finite state. Its gating and delta rule make that state far more useful, but exact recall from an arbitrary million-token history is still the reason Kimi Linear keeps periodic MLA layers.

PYTORCH REFERENCE · CONCEPTUAL KDA STEP

def kda_step(state, q, k, v, alpha, beta):
    # state: [B, d_key, d_value]; alpha: [B, d_key]
    decayed = alpha.unsqueeze(-1) * state
    retrieved = torch.einsum("bkd,bk->bd", decayed, k)
    error = v - beta.unsqueeze(-1) * retrieved
    next_state = decayed + torch.einsum("bk,bd->bkd", beta * k, error)
    output = torch.einsum("bkd,bk->bd", next_state, q)
    return output, next_state

Kimi Linear: why it stays hybrid

A fixed-size state cannot always perform exact retrieval from a huge context. Kimi Linear therefore does not replace full attention everywhere. It repeats three KDA layers, then one MLA layer. KDA handles most token mixing efficiently; periodic Multi-Head Latent Attention provides a global retrieval path.

KDAKDAKDAMLA↻repeat 3 : 1

The report applies NoPE to the MLA layers. This is not “no order at all”: KDA’s channel-wise decay becomes the position-aware operator and supplies recency bias, while the full-attention layers focus on global retrieval. The paper reports its NoPE model outperformed its matched RoPE variant on the listed long-context evaluation.

KDA is also rearranged into chunks: recurrence passes state between chunks, while work inside a chunk becomes parallel matrix multiplication. Its constrained diagonal-plus-low-rank transition avoids expensive operations in more general fine-grained linear-attention forms.

Attention Residuals (AttnRes)

Standard PreNorm residuals use hl = hl−1 + fl−1(hl−1). Every layer output is added with weight one, even after it has been carried through many later layers. The report argues that this grows hidden-state magnitudes and makes useful early features hard to select.

Here hl is the hidden state: the vector of features a token carries into layer l. fl−1 is the work performed by the previous layer, attention and an MLP, for example. The residual stream is the running h vector that flows around these layer transformations. Each layer can add a new feature, but it cannot point to one earlier feature and say “use that one now.”

AttnRes changes the question from “add the previous state” to “which earlier layer outputs are useful right now?” It treats earlier layer outputs as keys and values, and gives each destination layer l a learned pseudo-query wl.

The query is learned per layer; the actual attention weights are input-dependent because the source representations change by token. A deep layer can directly retrieve an earlier feature instead of requiring every useful signal to survive inside one cumulative residual stream.

Where AttnRes sits among residual designs

Residual design is often framed as a stability problem, but it is also a memory-access problem. During training, a gradient tells each parameter how a small change would affect the final error. In PreNorm, the skip connection passes h forward unchanged before the new layer output is added. This unchanged route is the “clean identity path”: gradients can travel backward through it without being repeatedly transformed. It helps deep networks train, but still repeatedly adds outputs to one running stream. PostNorm normalizes after each layer, which keeps feature sizes bounded, but that extra transformation can weaken the direct gradient route. Other methods modify the immediate predecessor rather than providing direct access to old layers.

DenseFormer Static mixture of previous outputs Direct access, but coefficients are fixed after training.
AttnRes Dynamic mixture of previous outputs Each depth chooses useful sources per input token.

AttnRes uses one pseudo-query wl per destination layer rather than deriving a query from the current activation. This may look restrictive, but it is deliberate: the source keys and values already change with the input, so the resulting weights remain input-dependent. More importantly, this decouples the cross-layer lookup from the layer’s forward computation, allowing the implementation to batch many depth queries efficiently.

A pseudo-query is simply a learned vector that asks what kind of feature a layer usually wants from earlier depth. It is not a token’s current content. The source keys and values still depend on the current token and prompt, so the same pseudo-query can assign different weights to different inputs. “Batching” means calculating lookups for several layers together as one large matrix multiplication, which is much faster on GPUs than launching many small operations.

Block AttnRes makes it practical

Full AttnRes needs each layer to read all earlier outputs, which is expensive at scale. Block AttnRes splits L layers into N blocks. It stores one representation per completed block; within the current block it also attends to the partial sum already computed.

Its two-phase schedule is the key systems idea. First, all pseudo-queries in one block attend to cached earlier blocks in one batched operation. Then layers inside that block run sequentially and merge the results with online softmax. The report measures less than 2% end-to-end inference-latency overhead on typical workloads.

Online softmax is a way to combine attention results calculated in separate pieces without storing every score at once. Here it combines attention over completed blocks with attention over the partially computed current block, while producing the same normalized weighted average as if every source had been processed together.

What connects the papers

Kimi Linear Attention Residuals
Axis Sequence / tokens Depth / layers
Baseline problem KV cache and quadratic retrieval Uniform residual accumulation
Main operation Gated, editable recurrent memory Softmax retrieval over prior layers
Practical compromise 3 KDA layers + 1 MLA layer Block summaries + intra-block attention
Core trade-off Finite state vs exact global recall Cross-layer access vs memory traffic

They are complementary. Kimi Linear is about how a layer mixes tokens; Attention Residuals is about what state a layer receives before it mixes tokens. Together they suggest a useful principle: use cheap structured state for the common path, then keep selective attention where exact retrieval matters.
